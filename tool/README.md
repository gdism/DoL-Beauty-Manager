# DoL 美化管家（内部验证预览）

当前修正版：**0.1.1**。修复原始 BJ 816 图目录遗漏身体/脸部转换，导致应用后角色仍原样的问题。替换与复测说明见 [BJ-0.1.1-FIX.md](BJ-0.1.1-FIX.md)。

管理器可读取已加载美化、img 目录或 ZIP，按真实来源和请求字节识别当前组合，执行已认证规则，应用、撤销、缓存并导出完整选定图片组合。完整旧包到 5.12 的全部布局和状态仍未验收，当前不是正式兼容发行版。

后续产品目标见 [产品需求](../docs/PRODUCT-REQUIREMENTS.md)，当前实现缺口见 [PROGRESS.md](PROGRESS.md)；桌面资源实测见 [PERFORMANCE.md](PERFORMANCE.md)。

## 安装与使用

1. 在已有 ModLoader（>=2.100.0）的游戏中加载 `DoLBeautyManager-M0.mod.zip`。文件名沿用早期测试入口，当前内容已超过 M0。通常使用这个 DOM 默认包。
2. `DoLBeautyManager-Twee.mod.zip` 是同一管理器的可选 Twee 接入包，需要已有 TweeReplacer 1.7.0 提供占位；DOM 协调器会接管占位并在需要时回退。两个包同名，只选一个加载。
3. 点击首页或游戏内侧栏的“美化管理”，扫描已加载来源。表格分别显示声明、登记、启用和可读状态；报告另列实际请求胜出者。
4. 直接替换 img 的来源需选择 img 文件夹，或导入包含 img/ 的 ZIP。浏览器不能自动枚举游戏目录。也支持 BSA 0/1/2A/2B 声明和 JSON5 列表。
5. 默认选择当前有效组合；下拉框可选择单一来源。禁用来源不混入默认组合。未知 JS/Twee 等运行依赖会阻止图片组合被称作完整独立包。
6. “检查并修复”只运行输入字节、目标源码与模型合同均匹配的认证规则，先准备结果；随后点击应用才生效。
7. 个别图片不可读或冲突时，可准备并“应用已验证独立组”。失败组整组保留上游，部分范围重载后仍保留，完整 ZIP 导出被阻止。先解决来源问题、重新扫描再准备完整组合。
8. “恢复修复前组合”撤销本管理器覆盖层，不等于原版回退。可导入固定官方原版 ZIP / img 目录；逐图校验通过后，“按已验证组回退原版”准备已认证整组，随后应用。坏图按明确声明确定回退组；一个基线组不可用时，其他完整组仍可独立应用，不完整范围无法导出完整 ZIP。
9. “导出完整 ZIP”包括已提交选定组合的全部图片，保留未修改图片，并包含必要初始化代码。正常完整组合可独立加载；部分组结果无法伪装成完整导出。

## 已验证规则

- 原始 893 样本：181 个经 5.12 实际请求验证的路径转换、46 组；889 样本：170 个转换、45 组。映射保持图片原字节，目标与既有目标哈希有明确前提。不是仅重命名旧规则目标版本。
- 原始893/889另补1个原子组：将两张精确匹配的全透明眼影源裁去透明尾列，并复制到四种眼型的开眼/半闭8目标路径；目标图层全部函数和来源追踪均绑定，旧未知路径保留。
- 840 样本：八张已知全透明眼影占位图，四个开眼/半闭依赖组，516×256 去除右侧透明列到 512×256。前 512 列 RGBA 保留，无重采样。含可见双帧控制用例。
- 睫毛家族新增四个完整组，共24张图：开眼/半闭睫毛和四级流妆。固定893/889/840样本的流妆单帧经40状态与3帧控制验证可直接复用，保持原字节；原版整组回退另有40状态对照及损坏组隔离验证。
- 旧四份规则的八种操作及顺序已与 Python 参照对照；整套旧规则尚未认证为 5.12 自动适配。尚未认证的其他动画帧数、来源布局、merge/mask 和未解释路径仍保留并报告。
- 2660 个有限场景用于诊断；未知路径不会被自动删除。有限场景覆盖不能代表全部游戏状态。

## 原版基线

固定[官方 0.5.12.13 标签](https://gitgud.io/Vrelnir/degrees-of-lewdity/-/tags/0.5.12.13)，提交 `0354ffeb81884323d70f2ec2338bcaa52567cb67`。

源码 ZIP SHA-256 为 `b2ce8961a2899ad2720dbf2d45bad19785219b2b83ebe214bffd82da5ec8327f`。基线共 18,735 张图片（18,570 PNG、142 GIF、23 个后缀为 .png 的 WebP），5 个非图片文件不作为基线图片。固定 ZIP 和逐图摘要验证后可缓存离线使用。

网络获取受浏览器跨域限制时，用界面的固定官方下载链接获取 ZIP，再导入，仍执行相同校验。本地玩家 img 快照不能据文件数量认定为干净原版。

## 保存、卸载与排障

只使用本工具自己的 `DoLBeautyManager-v1`、`DoLBeautyManager-baselines-v1` 数据库。原输入、派生结果、官方基线分开保存；持久化失败明确显示仅本次会话应用。上游来源、顺序、渲染函数变化后会拒绝恢复或导出旧结果。

卸载前先“恢复修复前组合”；需要清理本工具保存内容时使用“清理本工具数据”，再在 ModLoader 移除管理器。该操作不清理玩家存档或其他 Mod 数据库。完整导出包是独立 Mod，若已另行加载，需在 ModLoader 中单独移除它。

没有入口时先确认 ModLoader 已正常载入并查看控制台；DOM 默认包不依赖 ModHub 或 TweeReplacer。导出受阻时先下载检测报告，处理读取错误、来源变化或未知代码依赖后重新扫描。存储失败时保留页面；完整组合可先导出备份，部分组必须先解决不完整来源。
