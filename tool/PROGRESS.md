# 当前实现与后续目标

当前源码基线为0.1.1内部验证预览。已具备来源读取、目录/ZIP导入、精确样本规则、应用/撤销、持久化和独立zipmod导出。

这些能力不等于通用版本互转。新的产品目标见[产品需求](../docs/PRODUCT-REQUIREMENTS.md)，原生界面方向见[UI设计](../docs/UI-DESIGN.md)。

## 主要缺口

- 基于游戏本体规范变化的权威版本链、路径组合及逆向恢复管理。
- 每份美化及混合组件的理论适配版本识别。
- 独立备份与多结果管理、双树多选、img直接导出和原生三栏UI。
- 更完整的规则、原版依赖组、游戏状态、浏览器资源预算与Android验收。

旧版工作域计数不作为这些目标的总体完成率。未在此处给出未经验收的完成百分比或发布时间。
