# BJ 原始目录应用后角色不变：0.1.1 修复

## 原因

816 张原始 BJ 图片包含 `basenoarms-m.png`、`browlow.png`、左右分离虹膜等旧布局。此前 889/893 样本已经完成部分历史转换，现有规则漏掉了原始目录到该中间状态的步骤。

这会得到“44 组修复、43 组已适配”和 718 张输出，但身体、脸部主组未匹配，角色需要的新路径没有生成。应用覆盖本身成功，修复计数却不足以说明角色主图已适配。

## 使用修正版

1. 在 ModLoader 中用新的管理器包替换旧的 `DoLBeautyManager`，重新启动游戏。
2. 打开美化管理，确认标题显示 `0.1.1-m0`。
3. 导入同一份原始 `img` 目录，确认应用范围选中本次导入来源，再检查并修复。
4. 点击“应用完整所选组合”，关闭面板查看角色。相同 816 图样本的测试结果为 794 张输出；角色身体与脸部组成功转换。

已有旧导出包仍加载的情形也已测试；管理器应用层优先。无需修改原图。新规则改变适配指纹，旧保存结果可能被判为过期，重新扫描、修复、应用即可。

## 本次验证

- 两个精确输入原子组：身体 14 个目标、脸部及遮罩 103 个目标。
- 117 个目标的实际模型图层或遮罩渲染与直接字节控制一致。
- 四种虹膜及两个遮罩与保留的 Python 实现逐像素一致。
- 源图摘要变化时拒绝该组；其他独立组继续；重复转换不改变结果。
- 真实目录导入、旧导出包共存、现存静态和动画角色更新均有运行证据。

新增主图旧路径缺口提示：若身体或脸部仍只有旧路径，准备及应用提示会直接说明，不再只显示修复组数。此规则限定于已验证的原始 BJ 图片和 5.12.13 运行指纹；腮红布局、其他未覆盖动画和全游戏状态仍分别待验收。
